# Compute Laboratory

This repository is a deliberately minimized computational backend.

It contains only neutralized numerical interfaces and execution code required to run high-dimensional simulation/surrogate workloads. Scientific interpretation, semantic variable names, source-data provenance, methodological narrative, mappings, manuscripts, and publication artifacts are maintained elsewhere and are intentionally absent here.

Public identifiers follow a neutral schema:

- `X###`: input dimensions.
- `Y###`: response dimensions.
- `P##`: structural-profile identifiers.
- `G###`: grouping identifiers used for leakage-safe validation.
- `L###`: reserved evaluation flags.

Outputs from this repository are numerical compute artifacts only. They are not, by themselves, scientific conclusions.

## Execution boundary

The laboratory must never contain:

- semantic variable dictionaries;
- source-data names or provenance;
- research questions or hypotheses;
- publication text/PDFs;
- interpretation of response dimensions;
- private identifier mappings.

The private canonical repository remains the source of truth for interpretation and traceability.
